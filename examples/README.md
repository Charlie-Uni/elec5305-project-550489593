# Listening examples

[Repository home](../README.md) · [Listen on the website](https://charlie-uni.github.io/elec5305-project-550489593/#listen)

The website has four target sounds and 48 selectable mixtures: four interference
conditions at three levels for each target. Each mixture has its own gain-matched
clean control, giving 96 WAV files. These examples illustrate measured behaviour;
the experiment uses all 2,000 ESC-50 targets, not only these four examples.

| Collection | Targets | Metadata and attribution |
|---|---|---|
| Original examples | Can opening; dog | [Collection README](listening_own_20261109/README.md) · [source rights](listening_own_20261109/source_rights.json) |
| Added examples | Clock alarm; airplane | [Collection README](listening_own_20261110/README.md) · [source rights](listening_own_20261110/source_rights.json) |

The [page verification record](../results/listening_site_20261110/README.md)
checks reconstruction, choices, predictions, ranks and rate denominators. Full
experiment rates beside the examples distinguish captures per trial from captures
per error. Successful playback does not replace the author's listening assessment.

Keep controls and mixtures at the same playback volume. Original waveforms,
per-example filenames, checksums and attribution files are preserved, including
identical controls that belong to different manifest rows.
